## What's new in v0.1.2

A fix release for installing and updating.

### Fixed
- **ZIP updates no longer stall.** Updating with *Install Plugin from ZIP
  File* while monoink was running could stop part-way, leaving Decky's
  install dialog spinning. monoink now runs a private copy of its program,
  so Decky can always replace the plugin's files during an update.

### Updating from v0.1.1
Update **once using Install Plugin from URL** (the link below). A ZIP update
from v0.1.1 can still stall, because v0.1.1 itself has the old behavior;
from v0.1.2 onward, either method works.

If a link install seems to hang for a minute or two at the start, leave it
running: Decky first reports the install to its own plugin-store server and
waits for it even when that server is slow.
